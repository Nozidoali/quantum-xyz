## Design highlights

**Strategy pattern.** `SynthesisEngine.run` orchestrates a three-phase pipeline:
1. Support reduction (if `param.enable_compression`)
2. Short-circuit strategies (Trivial, ExactCNOT) — produce final answer without falling through
3. Competing strategies (MFlow, NFlow) — both run, engine picks minimum CNOT count

Strategies declare `applicable()` and `synthesize()`. The engine owns scheduling; strategies are single-purpose.

**Gate ABC.** Every concrete gate must implement `apply(state) -> state`, `cnot_cost() -> int`, `qubits() -> list[QBit]`. `conjugate()` is optional (raises by default; subclasses override).

**Real-amplitudes QState simplifies non-real gates.** Under the `np.real(...)` projection the library already uses, `RX(θ) = RZ(θ) = cos(θ/2)·I` as an operator on real-amplitude states. This let Phase 2 implement those `apply` methods as single-line scalar multiplications.

**Phase 1 unblocked a 150× speedup.** The "param is dropped via kwargs" bug meant dense states always took the m-flow path (intended for sparse states). Fixing the bug made the library pick n-flow for dense states — which happens to be much faster. `dense_random_n4` cases dropped from ~135s to ~0.07s each.

## Things that were out of scope for this refactor

- **Documentation updates.** README, sphinx docs, inline docstring prose are unchanged. A follow-up pass could add comprehensive docstrings.
- **Test reorganization.** `tests/test_algorithms/` still matches the old package name. A rename to `tests/test_synthesis/` would be consistent but is mechanical churn.
- **Removing `_reindex.py` dead code.** `reindex_circuit` is imported but only called on an unreachable code path (the engine's enable_reindex branch raises before any call). The function + file could be deleted.
- **Performance work.** The regression suite's `@pytest.mark.slow` cases (test_qsp_1, large Dicke) still take hours on slurm; no one looked at speeding them up.
- **Publishing a new PyPI version.** A release commit + version bump in pyproject.toml is needed to ship the refactored library.
