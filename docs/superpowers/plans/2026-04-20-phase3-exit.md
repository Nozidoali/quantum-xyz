## Design decisions made during execution

**`BasicGate` hardening.** The old class had `assert isinstance(target_qubit, QBit)` which gets stripped under `python -O`. The moved version uses `raise TypeError(...)` instead. Also the old class redundantly re-declared `apply`/`cnot_cost`/`qubits` as `NotImplementedError` stubs — those were dropped since `Gate` already declares them as abstract via the ABC machinery.

**Legacy aliases preserved in `xyz/gates/__init__.py`.** `QGate = Gate`, `RotationGate = RotationTrait`, etc. External scripts that still import the pre-Phase-2 names keep working. Phase 5 can drop them.

**`xyz/circuit/__init__.py` bridges two layers.** The `xyz.circuit` namespace still re-exports everything from `xyz.gates` and the relevant `xyz.decomposition.*` symbols, so `from xyz.circuit import X, map_muxy, QBit` still works. This is a migration-period convenience — Phase 4's package reorg is the right place to question whether `xyz.circuit` needs to keep those shims.

**Subagent auto-expansion in qcircuit.py.** The import-rewrite subagent noticed `qcircuit.py` uses `map_mcry_linear` directly (not just for re-export) and added an explicit `from xyz.decomposition.mcry import map_mcry_linear` at the top. Net positive: the old `from .qgate import *` was relying on transitive exposure.
